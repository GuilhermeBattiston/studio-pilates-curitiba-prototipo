# Studio Pilates Curitiba — protótipo

Protótipo não oficial de uma landing page para o **Studio Pilates Curitiba**, no Mossunguê, apresentado como proposta comercial de presença digital.

## Objetivo

Transformar a aula experimental no principal caminho de conversão, apresentando o Studio e a profissional responsável antes do contato pelo WhatsApp.

## Conteúdo do protótipo

- Página única responsiva para celular e computador
- Chamada principal para agendar aula experimental
- Apresentação da Dra. Daniela C. Calachi, fisioterapeuta
- Seção explicando uma possível jornada para a primeira visita
- Links para os canais públicos do Studio
- Identidade visual criada exclusivamente para a demonstração

## Avisos importantes

- Este é um **protótipo demonstrativo e não oficial**.
- Textos, serviços, horários e demais informações precisam ser validados pelo Studio antes de uma publicação definitiva.
- A imagem principal foi gerada por inteligência artificial para fins conceituais e não representa o espaço ou a profissional reais.
- O protótipo não coleta nem envia dados de visitantes.

## Como visualizar

Abra o arquivo `index.html` no navegador ou acesse a versão publicada pelo GitHub Pages.
